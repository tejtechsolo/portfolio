# TechSolo Portfolio

Premium responsive portfolio built with **Next.js App Router, TypeScript, Tailwind CSS v4 and Framer Motion**.

## Pages
- / Home
- /about About
- /projects Projects
- /projects/[slug] Project case studies
- /skills Skills
- /blog Blog
- /blog/[slug] Article pages
- /contact Contact

## Run
```bash
npm install
npm run dev
```

## Customize
Edit `lib/data.ts` for projects, skills and posts. Replace the hero initials with a real portrait when available and connect the contact form to your preferred email/API provider.
